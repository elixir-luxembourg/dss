# Use cases

![Use cases diagram](use-cases.svg)


## Share submission
### Appointing submitter
- DataSteward can appoint a submitter in the Draft phase

### Sharing with other users
- Submitter can share the submission with additional users.
- The users can view the submission but not edit.

## Export submission

System allows users to export submission in any phase. 

This is commonly needed in Approval phase when the submission metadata is attached to a contract being negotiated. 

### Export formats

- **PDF** 
- **MS Word document .docx** - easier for attachement to contracts
- **JSON** - or any other machine actionable format


## Attach file
Arbitrary files can be attached to the submission. These are commonly supporting documents like contracts, confirmation forms, de-identification procedure, ethics approvals, etc.

### Attachement Constraints

- **Allowed file types**: PDF, TXT, PNG
- **File size**: Controlled by server configuration
