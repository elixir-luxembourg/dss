
## Submission from a service clinicians / less involved parties
The provider is willing to upload the data but **metadata submission is seen as annoying**. Provider is either not researcher or has provided data in-kind. 

Full metadata is not needed or not available
- data not matching our data model
- data for preliminary analyses

Although agreement was concluded, the provider has no real motivation to go through lengthy submission process.

E.g. partial data are uploaded by a clinician as part of a bigger data collection efforts.

LCSB is supporting the submitter as much as possible
    - legal agreement template
    - sometimes even running the upload commands from provider's environment

Should our researcher act as submitter?
Or should he act as data steward?

1. Researcher pre-creates the submission selecting project and themselves as **recipient**.
2. Researcher pre-fills the submission and shares it with submitter.
3. Submitter will log into the platform and confirms the metadata is OK.
4. DS approves the submission
5. Data is uploaded by researcher or submitter
6. Recipient verifies the data and metadata is ok
7. Recipient marks the submission as complete
