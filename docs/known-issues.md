# Known issues

This page provides an overview of known limitations of the system which shall be considered before its adoption/integration. 

- submitter cannot finilize the submission unless all datasets are submitted
    -  solution: cancel datasets which are not ready and create new submission when time comes, submitting only datasets which are available    
- submitter cannot submit the data in batches
    - solution: duplicated submission and change the dataset name a bit to refer to the batch id


Issues and features are considered to be addressed and fixed are collected in the official github repository.
