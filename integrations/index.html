    Project flow diagram

    initiation

    • project gets funded
    • record in project database is created
      • PI, internal personnel,

    Data recieved from outside

    • contract covering data/sample processing is being negotiated
      • contract is signed
    • data submission is open in data submission system
    • data upload and ingestion can happen only when contract is in place
    • upon first ingestion, the project collection in iRODS is created
      • all users defined in project database have read access to this collection
      • existence of datasets are stored under the project entity in project databse
    • upon follow up ingestion,

    Data from samples

    • samples are recieved by post
    • project entity is created also in ELN
    • samples are processed in experiment -> dataset is generated
    • dataset can be somehow picked up by the ingestion module

    Data re-used from other project

    • request is submitted to access data / samples from original project
    • if approved, the data is provided by ? into the irods research space (automatically - good because provenance is recorded) or for download( bad because then its lost)

    Data from platforms

    • samples are submitted to platform
    • a) platform creates submission in submission system - recipient project will be the project of origin of the samples (this could be automated)
    flowchart TD
    A[Project Funded] --> B[Project Record Created in Project Database]
    B --> C[Define PI & Internal Personnel]
    C --> R
    R --> T{Contract needed?}
    T -- No --> V[Create copy]
    V --> K
    T -- Yes --> D[Contract Negotiation]
    D --> E[Contract Signed]
    E --> R
    R[Provision Assets] -- external data --> F[Open Submission in DSS]
    F --> G[Data Upload]
    K --> H1{Is it first dataset?}
    H1 -- Yes --> H[Create Project Collection in iRODS]
    H1 -- No --> J
    H --> I[Grant Read Access to Project Users]
    H --> J[Store Dataset Existence in Project Database]
    G --> P
    K[Ingestion] --> H

    %% Samples received by post
    R -- external samples --> L
    L[Samples Received] --> M[Project Entity Created in ELN]
    M --> N[Lab Experiment]
    N --> O[Dataset Generated]
    O --> P[Dataset Picked Up by Ingestion Module]
    P --> K

    %% Data re-used from other projectß
    R -- internal re-use --> Q
    Q[Request Access to Data/Samples from Original Project] --> S{Approved?}
    S -- Yes --> T
    S -- No --> U[Access Denied]

    %% Data from platforms
    L --> W
    W[Processing by platform] --> F
